Part 1. Classes, objects and references

Goal: a class is a blueprint, new builds an object from it, and a variable holds a reference to the object, not the object itself.
public class Pet {
    private String name;
    private int age;
    public Pet(String name, int age) { this.name = name; this.age = age; }
    public void birthday() { age++; }
    public void setName(String n) { name = n; }
    public String toString() { return "Pet[name=" + name + ", age=" + age + "]"; }
}

Press the lines of code below in any order. Watch the arrows. Try the order: line 1, line 2, line 3, then line 4, then print a and print b.

Check yourself: After b = a; how many Pet objects can still be reached? Why does a.birthday() change what b prints?
